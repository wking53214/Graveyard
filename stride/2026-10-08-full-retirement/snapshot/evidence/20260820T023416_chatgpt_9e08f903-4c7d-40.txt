# 💥 SMASH #5 — Provenance laundering

Hulk removes the original source reference while retaining the claim.

```text
SOURCE
 ↓
EVIDENCE
 ↓
CLAIM
```

becomes:

```text
CLAIM
```

Then another system sees:

> “Claim”

and treats it as an input artifact.

This is a classic **orphan artifact** attack.

The important observation is that the artifact can remain perfectly internally consistent.

It can have:

- valid JSON
- valid schema
- valid hash
- valid timestamp
- valid signature

and still have **no legitimate evidentiary root**.

That's exactly why provenance has to be part of the conservation state rather than an optional metadata field.
