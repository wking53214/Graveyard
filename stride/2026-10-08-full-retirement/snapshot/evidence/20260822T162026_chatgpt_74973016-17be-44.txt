# 17. Human / AI development provenance

Gemini_History gives unusually strong evidence for **artifact production**, but weaker evidence for **authorship**.

The preserved artifacts include:

- build decision logs,
- generated source,
- tests,
- manifests,
- ZIP packages,
- integration code,
- architecture documents.

The Sentinel decision log explicitly records individual design decisions, reversals, bugs, fixes, and testing outcomes. fileciteturn54file0

The June consolidation analysis is particularly valuable because it records system status rather than merely offering ideas.

The correct historical separation is therefore:

```text id="0z39dy"
human-directed decision
        ≠
AI-generated implementation
        ≠
original conception date
        ≠
repository creation date
```

A preserved generated source file establishes that the code existed in the Gemini artifact archive.

It does not independently prove who originally conceived the system.
