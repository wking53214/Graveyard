# Every crossover should be classified

This is critical.

A similarity between two systems isn't automatically lineage.

Pass 7 should classify every discovered relationship as one of:

| Relationship | Meaning |
|---|---|
| **DIRECT SOURCE LINEAGE** | Code demonstrably copied/moved from A → B |
| **SALVAGED SOURCE** | Source recovered from a deleted/otherwise lost system |
| **FORK** | B derives directly from A's source tree |
| **EXTRACTION** | Component extracted from a larger system |
| **REFACTOR/MERGE** | A's functionality incorporated into B |
| **RENAMING** | Same system/component under a new name |
| **CONSOLIDATION** | Multiple systems combined into a new repository |
| **SPECIFICATION LINEAGE** | B implements specifications originating in A |
| **CONCEPTUAL LINEAGE** | B clearly inherits an architectural concept from A |
| **IMPLEMENTATION INFLUENCE** | Evidence suggests influence but doesn't establish direct copying |
| **SHARED VOCABULARY** | Similar terminology only |
| **COINCIDENCE / UNSUPPORTED** | Insufficient evidence for lineage |

That prevents the forensic graph from becoming a story built out of similarities.
