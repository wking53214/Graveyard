# The key concept we were missing: multiple canonical sources

This is the biggest correction.

I don't think your architecture should have **one physical "single source of truth."**

It should have a:

## Global Source-of-Truth Protocol

with **domain-specific canonical stores**.

For example:

```text
                    GLOBAL GOVERNANCE
                     SOURCE-OF-TRUTH
                          PROTOCOL
                              │
        ┌─────────────┬───────┼─────────┬─────────────┐
        ▼             ▼       ▼         ▼             ▼
     CCC/SOC      Resume MOB  TIE    Innovation    Code
 constitutional   professional      OS           registry
    truth           truth         evidence        truth
        │             │       │         │             │
        └─────────────┴───────┼─────────┴─────────────┘
                              ▼
                           GRAPH
```

The **protocol** determines:

- what counts as canonical
- who can authorize promotion
- how provenance is retained
- how contradictions are represented
- how one domain can reference another
- how historical state is preserved
- how deletion/erasure propagates
- how a domain's canonical truth can be challenged

That's far more scalable than making Resume_OS the global database.
