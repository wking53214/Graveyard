# The Affective Variant

`HISTORICAL_STATEMENT` · primary source `ARLF-03342`

This directory holds the **affective branch** of ARLF: the *Affective Recursive Loop Framework*, in
which the Jester reads physiological and sentiment signal, converts it to mathematical gradients, and
closes the training loop on emotion.

It is not the canonical reading of ARLF in this repository. See `NOMENCLATURE.md` for the
determination. It is preserved here in full, at the same evidence grade as everything else, for four
reasons.

**It is the specification that was actually written.** *Birth and Structure of ARLF* (`ARLF-03342`,
2026-04-08T02:35:29Z) is the only complete four-section framework document in the corpus. The
architectural reading has doctrine, a realized stack and a named mechanism, but it never got a
document like this one.

**It is the version that went to review.** Everything in `adversarial/` targets this branch. The six
critiques, the full-architecture exposure, the Black Paper and its unanimous INCINERATE verdict all
respond to the affective specification, not the architectural one. Without these documents the
adversarial record has no subject.

**It is the version that was purged.** The terminal classification of 2026-05-30 names this branch
specifically: "An experimental, highly inflated concept that was later deemed a systemic hazard and
purged" (`ARLF-01753`). The architectural reading's survival is only legible against this branch's
destruction.

**It defines the successor architecture by negation.** Layer 5 of the No-Trust Stack, the Joy Dial and
the Relational Interface exist as specifications of what this branch must not be permitted to do. Read
`spec/02_DETERMINISTIC_STACK.md` without this directory and those three components look arbitrary.
