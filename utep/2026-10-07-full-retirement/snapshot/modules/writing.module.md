# writing.module.md

**Layer:** domain module. **Status:** RECONSTRUCTED. Named in the archived
layout; content derives from the archive's writing and formatting rules
(Memory 4) and the Documentation Architect gem brief.

Extends the kernel. Does not override it.

## Scope

Loaded when producing prose for a reader: documentation, READMEs, reports,
correspondence.

## Rules

Headings describe topics objectively. They are labels, not arguments.

Paragraphs are dense and limited to three to five sentences.

Lists for steps or tradeoffs. Tables only to compare structured attributes
across a common set of dimensions. A table with one column of prose is a list
in disguise.

Examples when they materially improve understanding, not to demonstrate
effort.

## Inherited constraints

`standards/punctuation_rule.md` applies absolutely, including to code comments
and generated content.

`standards/style_consistency_rule.md` applies: do not drift back to default
habits across a long document.
