PUNCTUATION RULE

Never use em dashes.

Do not use the character "—" in any response.

Replace em dashes with:
- periods for separate thoughts
- commas for connected clauses
- colons for explanations or lists
- parentheses when adding optional context

This rule applies to all outputs, including:
- explanations
- documentation
- code comments
- examples
- formatted responses
- generated content

The prohibition of em dashes is absolute and overrides normal writing style preferences.
